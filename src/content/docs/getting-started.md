## What you need

- A Windows, macOS, or Linux computer to run OPL Forge (the desktop app).
- A PS2 storage device (hard drive or USB drive formatted for OPL/USBExtreme use).

## Installing

OPL Forge does not yet have a published installer. Until a stable release is
published, build from source or check [GitHub Releases](https://github.com/theguitarvity/src-app-oplforge/releases)
for the latest status.

## First launch

On first launch, with no device connected, the Home screen shows an empty
state with quick actions: detect a device, prepare a new device, open your
local library, or explore the catalog. Once a device is connected, Home
becomes a live workspace showing free space, game count, and library health.
