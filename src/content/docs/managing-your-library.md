## Unified library

The Library view combines PS2 games, PS1 games, and homebrew Apps in one
place, with grid and list layouts.

## Importing games

Use the PS2/PS1 import flow to detect Game IDs automatically and plan
storage placement (FAT32/USBExtreme-aware).

## Status badges

Each entry shows a status badge reflecting its real state:

- `ready` — verified and playable
- `needs_attention` — a problem was detected
- `fragmented` — see [Understanding Fragmentation & Repair](/oplforge/docs/understanding-fragmentation-repair/)
- `invalid_name` — filename doesn't match expected conventions
- `validation_warning` — a non-blocking validation issue was found

## Detail drawer

Selecting a game opens a detail drawer with contextual actions: validate,
check fragmentation, rename, or test in PCSX2.
